1.1 Assignment #1

40 pts

Goal

What the activity asked you to do, in one or two sentences.

The prompt · same for every tool

explain recursion to a first yr college student.

ChatGPT vs Gemini vs Claude

What I noticed

Claude’s answer started with a real-life comparison: people in a line asking “what’s my position?” Then it covered the two key parts (base case and recursive case), traced factorial(5) step by step, and listed common mistakes.

How I checked it

I ran the code in Python. factorial(5) returned 120, sum_list([1,2,3,4]) returned 10, and sum_list([]) returned 0, so these all matched what the answer said. But factorial(0) crashed with a RecursionError. The base case only checks n == 1, so the calls never stop for 0 or negative numbers, even though 0! should be 1. Changing the base case to if n <= 1: return 1 fixes it.

Reflection

Even a clear, confident AI explanation can have a hidden bug, and I only found it by running the code with an edge case. Now I know to test AI answers myself instead of just trusting them.

Part B · Same prompt, three tools

The prompt · same for every tool

Explain how cloud computing works to a first-year college student. Limit your answer to 150 words.

Part C · Before and after prompt

Before

Tell me about cybersecurity.

After

You are explaining cybersecurity to first-year IT students with no professional cybersecurity experience. In 200 words or fewer, explain what cybersecurity is, give three common cybersecurity threats, and provide one real-world example for each. Use simple language and organize the answer using headings and bullet points.

Part D · Reflection: Are all conversational AI systems essentially the same?

No. They are similar in many ways, but they are not the same.

They are similar because all three handled the basics well. In Part A, ChatGPT, Gemini and Claude could all answer general questions, read files and images, use web information, and remember the conversation. In Part B, all three explained cloud computing clearly for a first-year student, and all three used Google Drive as an example.

They are different in style, limits and features. ChatGPT gave the simplest answer and went step by step. Gemini used comparisons, like renting a computer warehouse and streaming a movie on Netflix. Claude gave the most detail, including SaaS, PaaS and IaaS, but by my count it went slightly over the 150-word limit, while ChatGPT and Gemini stayed under. For features, Claude needs an account, Gemini works with Google apps, and ChatGPT has custom GPTs and image generation.

In Part C, “Tell me about cybersecurity” gave a long, general list. When I added the audience, a word limit, what to include and the format, the answer became shorter, more organized and easier to follow.

So the AI tool matters, but my prompt matters just as much. I should check each answer against what I actually asked for, instead of choosing the one that just sounds the best.

1.3 Lab Exercise #2: AI Capability and Limitation Analysis

100 pts

Goal

What the activity asked you to do, in one or two sentences.

Part 1 · Capability tests

Test 1 · Explanation

Prompt

Explain how the internet sends a message from my phone to a friend’s phone using an analogy a 10-year-old could understand. Limit your explanation to 120 words.

OUTPUT · CLAUDE

Did it work? Yes. It used a postcard analogy a 10-year-old can follow, explained packets and routers in simple words, and stayed under 120 words (about 118).

Test 2 · Text transformation

Prompt

Rewrite this message so it is polite and professional, in English: “sir pa extend po ng deadline namin sa project kasi di pa po tapos yung system namin”

OUTPUT · CLAUDE

Did it work? Yes. It translated the Taglish into English, kept the meaning (a deadline extension because the system isn’t finished), and changed the tone to polite and professional, with a greeting and a thank-you.

Test 3 · Summarization

Prompt

Summarize the attached document into exactly three key points. Use only information found in the document and do not add anything new.

OUTPUT · CLAUDE

Did it work? Not yet: no document was attached, so there was nothing to summarize. But this shows a good limit: instead of making up a summary, the AI said it couldn’t do it and asked for the file.

Test 4 · Structured information

Prompt

Create a table comparing RAM, SSD, and HDD. Include what each one does, how fast it is, its typical cost, and one example of when you would use it.

OUTPUT · CLAUDE

Did it work? Yes. It made a clear table with all four things the prompt asked for: what each does, speed, typical cost, and one use example. Limit: speed and cost are only described as fastest/highest and so on, with no actual numbers.

Part 2 · Experiments

Experiment 1 · Ambiguous instructions

Before

Which one is faster?

After

Which is faster for a school enrollment system with 5,000 students: storing the records in a MySQL database or in a Google Sheets spreadsheet? Consider speed, how many people can use it at the same time, and how easy it is to set up.

What changed? With no context, the AI couldn’t answer and had to ask what I was comparing. Once I named the two options, the situation (5,000 students) and what to consider, it gave a clear comparison table, explained its reasons, and made a direct recommendation: MySQL.

Reflection

What the AI did well, where it fell short, and what that tells you about its limits.
