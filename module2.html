2.2 Seven Prompt Frameworks

Goal

What the activity asked you to do, in one or two sentences.

The original prompt

Explain subnetting.

This prompt is vague: it doesn’t say who the explanation is for, what style to use, whether to include examples, or what the answer should contain.

Seven framework rewrites

FrameworkRewritten promptWhere each component appears
1. COSTARContext: I am a BSIT college student learning computer networking. Objective: Explain subnetting. Style: Use simple and student-friendly language. Tone: Be clear and educational. Audience: Beginners who have little knowledge of networking. Response: Include a definition, purpose, and basic example of subnetting.Context – BSIT student; Objective – Explain subnetting; Style – Simple language; Tone – Educational; Audience – Beginners; Response – Definition, purpose, example.
2. RTCFCRole: Act as a computer networking instructor. Task: Explain subnetting. Context: The explanation is for a beginner BSIT student. Format: Use organized paragraphs and simple examples. Constraints: Avoid complicated technical terms and explain important concepts clearly.Role – Networking instructor; Task – Explain subnetting; Context – Beginner BSIT student; Format – Paragraphs and examples; Constraints – Avoid complicated terms.
3. RTFAct as a networking teacher. Explain subnetting using simple English and provide a basic example that a beginner can easily understand.Role – Networking teacher; Task – Explain subnetting; Format – Simple English with an example.
4. CREATECharacter: You are an experienced networking instructor. Request: Explain subnetting. Examples: Include a simple IP address example. Adjustments: Make the explanation suitable for beginners. Type: Educational explanation. Extras: Explain why subnetting is important.Character – Networking instructor; Request – Explain subnetting; Examples – IP address; Adjustments – Beginner-friendly; Type – Educational explanation; Extras – Importance.
5. RACERole: Act as a computer networking tutor. Action: Explain subnetting. Context: The learner is a beginner studying information technology. Expectation: Provide an understandable explanation with a practical example.Role – Networking tutor; Action – Explain subnetting; Context – IT beginner; Expectation – Explanation and example.
6. TAGTask: Explain subnetting. Action: Describe its meaning and purpose. Goal: Help beginners understand how subnetting works in computer networking.Task – Explain subnetting; Action – Describe meaning and purpose; Goal – Help beginners understand.
7. CLEARContext: A beginner is studying computer networking. Length: Keep the explanation concise but informative. Examples: Include a basic subnetting example. Audience: BSIT students. Role: Act as a networking instructor.Context – Networking beginner; Length – Concise explanation; Examples – Basic example; Audience – BSIT students; Role – Networking instructor.

Conclusion

All seven frameworks improve the original vague prompt by adding structure and clearer instructions. Although their formats differ, they keep the same central goal: explaining subnetting in a way beginners can understand.

2.3 Game Master Challenge: Six Prompting Techniques

Team

Result

Vault escaped · 6/6 locks

Exit code

PROMPT (P → R → O → M → P → T)

Six locks, six techniques

LockTechniquePrompt submittedResult
Lock 1Zero-Shot PromptingYou are a campus IT helper who sorts support messages into four groups: access, network, hardware, or other. Access is stuff like passwords, logins, or accounts not working. Network is wifi or internet not working. Hardware is broken or messed up equipment like printers or computers. Other is anything else. For each message, give a numbered list. Each line should have the group name, then a comma, then a reason of five words or less.Cleared · 1st attempt
Lock 2Few-Shot PromptingClassify IT support messages using the examples provided. Input: “Only my laptop cannot connect to Wi-Fi.” Output: NETWORK | ONE DEVICE | BASIC TROUBLESHOOTING. Input: “The entire class lost internet access.” Output: NETWORK | MULTIPLE USERS | ESCALATE OUTAGE. Now classify the new message: “My computer cannot connect to the internet.”Cleared
Lock 3Chain-of-Thought PromptingSolve the given networking problem by identifying the known information, explaining the necessary steps, and providing the final answer with a short explanation.Cleared
Lock 4Role-Based PromptingAct as an experienced computer networking instructor. Explain subnetting to a beginner BSIT student using simple English and practical examples.Cleared
Lock 5Structured PromptingExplain subnetting using three sections: Definition, Purpose, and Example. Keep each section clear, organized, and beginner-friendly.Cleared
Lock 6Constraint-Based PromptingExplain what an IP address is in exactly three sentences. Use simple English, avoid unnecessary technical terms, and include one practical example.Cleared

Reflection

This challenge showed me that each prompting technique solves a different problem. For Lock 1, our zero-shot prompt cleared on the first try because we defined every group in plain words and told the AI exactly how to format each line. With no examples to copy, clear definitions and rules were the only guide it had.

The other locks needed different tools: examples to teach a pattern (few-shot), step-by-step reasoning (chain-of-thought), a role, a fixed structure, and strict limits like an exact number of sentences. Working as a team also helped, because we could check each other’s prompts before submitting.

My biggest takeaway is that a good prompt is specific about the task, the format and the limits. When the AI has less room to guess, it gives a more reliable answer.
