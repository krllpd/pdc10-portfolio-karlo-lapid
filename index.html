Final reflection

What I learned in PDC10

When I started PDC10, I thought using AI was mostly about knowing which tool to open. Looking back at this portfolio, the bigger lesson is that the answer depends on me: on how clearly I ask and how carefully I check. In Lab Exercise #1, “Tell me about cybersecurity” gave me a long, general overview. When I rewrote it for first-year IT students, with a 200-word limit, three threats, an example for each, and headings, I got a short, organized answer that did exactly what I asked. In Lab Exercise #2, “Which one is faster?” only got a question back, but once I named MySQL and Google Sheets, a 5,000-student enrollment system, and what to compare, the AI gave a clear table and a direct recommendation.

The second lesson was to never trust an answer just because it sounds confident. In Assignment #1, all three tools explained recursion well, but when I ran Claude’s factorial code with 0, it crashed with a RecursionError because the base case only checked n == 1. Changing it to n <= 1 fixed it. I also caught smaller things by counting and comparing: in the cloud computing test, ChatGPT and Gemini stayed under the 150-word limit, while Claude’s answer went slightly over. Even while putting this portfolio together, an AI summary claimed all six Prompt Vault locks passed on the first try and listed prompts that were not the ones we actually submitted, so I only used what our real ledger showed.

The games turned these ideas into practice. In the Prompt Vault, our Lock 1 prompt passed on the first attempt because it defined every group in plain words and set an exact format for each line. The Broken Bot Labyrinth showed the user’s side: a bot that asks for ten things at once, wants a birthday and address it doesn’t need, or just says “contact IT” makes people give up. In the Lost Context Archive, we had to keep only the latest facts after the student corrected their program and year, ignore the unrelated coffee-shop question, never use the shared password, and not invent a deadline that no source supported.

Personalizing ChatGPT in Module 2 tied it all together. The instructions I ended up with ask it to explain the reasoning behind its answers so I can explain them myself. That is what I want to keep from this course: write prompts with a clear audience, task, format and limits; test the output, especially code and numbers; and treat AI as a study partner whose work I still have to check.
